# Coal Dynamics

**Anthracite** is a stereo three-band saturator module for [VCV Rack 2](https://vcvrack.com/).

- **Developer:** Manuel Blanco
- **License:** MIT

## Introduction

The **Coal Dynamics** plugin brings the **Anthracite** module to
[VCV Rack](https://vcvrack.com/). Anthracite splits a stereo input signal into a **Low**, a **Mid**
and a **High** band, applies a selectable saturation curve with per-band drive, and sums the bands
back into the stereo output.

It is intended for mixing, creative sound design and mastering tasks that require three-band
saturation with per-band character and drive.

## Installation

### From the VCV Library

The plugin is distributed through the VCV Library. Open **Library** in Rack and install
**Coal Dynamics**. Rack keeps the plugin updated.

Version **2.8.3** of the **Coal Dynamics** plugin is the version submitted to the VCV Library.

### Manual installation

Alternatively, install a plugin package downloaded from the **GitHub Releases** page of the
[Coal Dynamics repository](https://github.com/mblancosound/VCV-Multiband-Saturator):

1. Download the plugin package (`.vcvplugin`).
2. In Rack, open **Help > Install plugin file...** and select the downloaded file.
3. Restart Rack.
