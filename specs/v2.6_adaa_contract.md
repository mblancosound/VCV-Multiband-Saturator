(`curveNames()` usa `<vector>`/`<string>`: no se toca y no entra nunca en el camino de audio).

```cpp
/** Umbral del fallback ADAA1, en unidades de u (voltios post-curveDrive). */
static const float ADAA_EPS = 1e-3f;

inline float logCosh(float u);
inline bool  curveSupportsAdaa(int curve);
inline float curveAntiderivative(float u, int curve);
inline float applyCurveAdaa(float u, float &uPrev, int curve);
```

### 1.1 Contratos

| Símbolo | Semántica | Dominio | Escalado por `TRIM` |
|---|---|---|---|
| `logCosh(u)` | `ln(cosh u)` estable en `float` para todo `u` finito | `u` finito; sin límite de magnitud | no |
| `curveSupportsAdaa(curve)` | `true` solo para `TANH, CUBIC, ARCTAN, HARD, FOLDBACK, SINEFOLD`; `false` para `CLEAN, TUBE, DIODE` e ids inválidos | cualquier `int` | — |
| `curveAntiderivative(u, curve)` | `F(u) = TRIM[curve] · ∫ f_raw(u) du`, con `f_raw` **idéntica** a la rama correspondiente del `switch` de `applyCurve` | todo `u` finito; sin recortes de dominio | **SÍ** (explícito) |
| `applyCurveAdaa(u, uPrev, curve)` | Paso ADAA1 con fallback; devuelve `y` **ya escalada por `TRIM[curve]`** (mismo contrato que `applyCurve`); escribe `uPrev = u` si y solo si la curva soporta ADAA | `u`, `uPrev` finitos | **SÍ** (explícito) |

**Propagación del TRIM (obligatoria).** `applyCurve` devuelve `y * TRIM[curve]`. Para que
`ΔF = F(u) − F(uPrev)` sea comparable con `f = applyCurve(u)`, la antiderivada se escala **una sola vez** dentro de
`curveAntiderivative` (`return y * TRIM[curve];`, mismo patrón que `applyCurve`). El paso ADAA **no** vuelve a
multiplicar. Consecuencia: `(F(u) − F(uPrev)) / (u − uPrev) → TRIM[curve] · f_raw(mid)` y el fallback
`applyCurve(u, curve)` cae en la misma escala. **Prohibido** devolver `F` sin escalar y multiplicar después
(rompe la igualdad con el fallback en ±1 ulp y no aporta nada: el coste es el mismo).

`applyCurveAdaa` toma `uPrev` **por referencia** (`float &`): la actualización del historial es parte del contrato y
así no puede olvidarse en ninguno de los 6 puntos de llamada. Coste cero: `inline` + referencia = registro.

### 1.2 Implementación literal (copiar tal cual)

```cpp
inline float logCosh(float u) {
  const float a = std::fabs(u);
  if (a < 0.5f) {
    const float s = std::sinh(0.5f * a);
    return std::log1p(2.f * s * s);              // ln(1 + 2 sinh^2(a/2))
  }
  return a + std::log1p(std::exp(-2.f * a)) - 0.6931471805599453f;
}

inline bool curveSupportsAdaa(int curve) {
  return curve == TANH || curve == CUBIC || curve == ARCTAN ||
         curve == HARD || curve == FOLDBACK || curve == SINEFOLD;
}

inline float curveAntiderivative(float u, int curve) {
  float y;
  switch (curve) {
    case TANH:
      y = logCosh(u);
      break;
    case CUBIC: {
      const float a = std::fabs(u);
      y = (a <= 2.f) ? a * a * (0.75f - 0.125f * a * a) : (3.f - a);
      break;
    }
    case ARCTAN: {
      const float pi = 3.14159265358979f;
      const float w = 0.5f * pi * u;
      y = (4.f / (pi * pi)) * (w * std::atan(w) - 0.5f * std::log1p(w * w));
      break;
    }
    case HARD: {
      const float a = std::fabs(u);
      y = (a <= 1.f) ? 0.5f * a * a : (a - 0.5f);
      break;
    }
    case FOLDBACK: {
      float p = std::fmod(u, 4.f);
      if (p < 0.f)
        p += 4.f;
      if (p <= 1.f)
        y = 0.5f * p * p;
      else if (p <= 3.f)
        y = 2.f * p - 0.5f * p * p - 1.f;
      else
        y = 0.5f * p * p - 4.f * p + 8.f;
      break;
    }
    case SINEFOLD:
      y = -std::cos(u);
      break;
    default:
      y = logCosh(u);
      curve = TANH;
      break;
  }
  return y * TRIM[curve];
}

inline float applyCurveAdaa(float u, float &uPrev, int curve) {
  if (!curveSupportsAdaa(curve))
    return applyCurve(u, curve);                 // CLEAN/TUBE/DIODE: directa, SIN tocar uPrev
  const float du = u - uPrev;
  float y;
  if (std::fabs(du) >= ADAA_EPS)
    y = (curveAntiderivative(u, curve) -
         curveAntiderivative(uPrev, curve)) / du;
  else
    y = applyCurve(u, curve);                    // fallback epsilon
  uPrev = u;
  return y;
}
```

### 1.3 Tabla curva → `f_raw` → `F` (derivación cerrada, pieza a pieza)

`f_raw(u)` es la rama de `applyCurve` **antes** de `× TRIM`. `F(u) = TRIM[curve] · F̃(u)`.

| Curva | `f_raw(u)` | `F̃(u)` literal | Estabilidad numérica |
|---|---|---|---|
| `TANH` | `tanh u` | `F̃ = ln(cosh u)` | `ln cosh a = a + log1p(exp(-2a)) - ln 2` (a = \|u\|) para `a ≥ 0.5`: sin `cosh` (no desborda) y sin cancelación de `ln2`. Para `a < 0.5`: `log1p(2 sinh²(a/2))`, exacto a escala `a²`. Crece como `\|u\| - ln2` (NO satura). |
| `CUBIC` | `1.5·clamp(u - u³/3, -2/3, 2/3)` | `\|u\| ≤ 2`: `0.75u² - 0.125u⁴`; `\|u\| ≥ 2`: `3 - \|u\|` | **Punto de ruptura en \|u\| = 2, NO en 1.** `u - u³/3` vale `-2/3` en `u = 2` (raíz `u³-3u-2 = (u-2)(u+1)²`) y `+2/3` en `u = -2`. En `-2 < u < 2` el clamp no actúa. `F` es par y continua en `\|u\|=2` (ambas ramas valen 1.0). |
| `ARCTAN` | `(2/π)·atan(πu/2)` | `w = πu/2`; `F̃ = (4/π²)·(w·atan w - ½·log1p(w²))` | `log1p(w²)` (no `log(1+w²)`): estable en `u→0` y sin desbordar hasta `u ≈ 10^19`. Asíntota: `F̃ ≈ u - 4/π² - (4/π²)·ln(πu/2)` (pendiente 1). |
| `HARD` | `clamp(u, -1, 1)` | `\|u\| ≤ 1`: `0.5u²`; `\|u\| ≥ 1`: `\|u\| - 0.5` | Par, continua en `\|u\|=1` (ambas ramas 0.5). Sin transcendentales. |
| `FOLDBACK` | triangular plegada, periodo 4, `y ∈ [-1,1]` | `p = u mod 4 ∈ [0,4)`: `p ≤ 1`: `0.5p²`; `1 ≤ p ≤ 3`: `2p - 0.5p² - 1`; `p ≥ 3`: `0.5p² - 4p + 8` | `F` es **periódica de periodo 4** (media de `f` nula) y está acotada: `0 ≤ F̃ ≤ 1`. Error absoluto de redondeo ≤ 1 ulp de 1 → el mejor condicionado de las seis. Ramas continuas en `p = 1, 3, 4` (0.5, 0.5, 0.0). |
| `SINEFOLD` | `sin u` | `F̃ = -cos(u)` | Acotada `\|F̃\| ≤ 1`; la constante aditiva es irrelevante (`Δ` la cancela). Para `\|u\|` grande el error de reducción de argumento de `cos` es ~`eps·\|u\|` (≈ 3e-6 a `u = 55`). |

Los ids `CLEAN`, `TUBE`, `DIODE` **no tienen rama válida** en `curveAntiderivative` y no deben llamarla (`CLEAN` es
lineal; `TUBE`/`DIODE` fuera de alcance, §4.1).

> ### 1.4 CORRECCIÓN MATEMÁTICA BLOQUEANTE (TANH)
>
> `specs/v2.6_quality_spec.md` §4.1 lista como antiderivada de `tanh` la expresión `u·tanh(u) - ln(cosh u)`. **Es
> incorrecta**: `d/du[u·tanh u - ln cosh u] = u·sech²u`, no `tanh u` (comprobación: en `u=1` vale `0,3278`, mientras
> `∫₀¹tanh = ln cosh 1 = 0,4338`). Implementarla haría que ADAA1 aproximase `u·sech²u` (nula en saturación): T-ADAA-TANH
> y T-ADAA-THD fallarían y el TANH con `adaa=on` sonaría a "gate" en vez de a saturación.
>
> **F congelada: `F(u) = TRIM[TANH] · ln(cosh u)`**, con `ln cosh` calculado por `logCosh()` (§1.2). El resto de la
> §4.1 queda intacto (SINEFOLD, HARD, CUBIC, ARCTAN y FOLDBACK se confirman tal cual). Esta corrección no cambia
> ninguna decisión de producto: mismo alcance, misma tabla de curvas, mismo `TRIM`, mismo default `"adaa": false`.

## 2. ε: valor congelado y justificación

```cpp
static const float ADAA_EPS = 1e-3f;   // unidades de u (V post-curveDrive); absoluto, no relativo
```

**Corrige** el "p. ej. 1e-4" de §8 R1. Se fija **1e-3f** por tres cotas medidas sobre este código:

1. **Cota superior (no romper el ADAA de audio).** El fallback sustituye el cociente por `f(u)`; el error de ese
   cambio es `≤ |TRIM·f'|max · ε/2`. `|TRIM·f'|max = 1.7631` (FOLDBACK, `|f'| = 1`) → discontinuidad
   `≤ 8.8e-4 V ≈ -61 dBV`. Inaudible y por debajo de cualquier artefacto del FIR a 1x.
2. **Cota inferior (no desactivar el ADAA).** `ε = 1e-3 V/muestra` a 48 kHz equivale a una pendiente de **48 V/s**;
   un seno de 5 V la alcanza solo a `f ≈ 1,5 Hz`. A 20 Hz / 5 V el `|du|` máximo es `0,0131 V` (13× ε) y la fracción
   de muestras que caen en el fallback es `(2/π)·ε/(2A·sin(Δθ/2)) ≈ 5 %`, todas en los extremos del seno, donde
   `f' ≈ 0` y el fallback es exacto a `O(du²)`. Los casos de alias (5 kHz, 4x) tienen `|du|` típico `≈ 9 V`: el
   fallback afecta a `< 0,01 %` de muestras → **no compromete los umbrales de §7**.
3. **Condicionamiento en `float` (por qué 1e-3 y no 1e-4).** `ΔF` se calcula restando dos valores de hasta
   `|F|max ≈ 55` (`TANH/ARCTAN/HARD` a `u = 5 V × drive 11`), con error absoluto `≈ 2·2^-24·55 = 6.6e-6`. El cociente
   hereda `6.6e-6/|du|`: con `ε = 1e-3` el error relativo en el borde es `≤ 0,7 %` (-43 dB); con `1e-4` sube a
   `≈ 6,6 %` (-24 dB) sobre las pocas muestras del pico → riesgo real para el criterio 5 (T-ADAA-THD, `+0,5 dB`).
   El régimen `|du| < 7e-3` (error `> 0,1 %`) solo lo alcanza una señal cuasi-DC.

**Invariantes.** `ADAA_EPS` NO depende de `sampleRate` ni de `oversampling` → **no se recalcula en
`onSampleRateChange()`** (Regla 3 no aplica: no es un coeficiente de filtro). Comparación literal
`std::fabs(du) >= ADAA_EPS` (incluye `du = ±ε` en la rama ADAA y `du = 0` en el fallback).

**Finitud (garantía).** Por el teorema del valor medio, `y = (F(u)-F(uPrev))/(u-uPrev) = f(ξ)` para algún
`ξ ∈ [u, uPrev]`; como las seis `f` están acotadas por `±1`, `|y| ≤ TRIM[curve]` para toda entrada finita. No hay
NaN nuevos y **T-NAN no necesita cambios** (sigue a `adaa = 0`; el riesgo de no-finito queda cubierto por esta cota).

Arnés desechable C++11 **fuera del repo** (MinGW-w64, `-O2`), con la implementación literal de §1.2 y doble precisión
como referencia. No forma parte de `test/` y no se versiona; sirve para respaldar las tres cotas de arriba.

| `u(t)` | Fallback | `max abs(float − double)` | `max rel` |
|---|---|---|---|
| `TANH`, 5 kHz / Vpk 55 / 4x | 0,00 % | 2,4e-7 | 2,4e-7 |
| `FOLDBACK`, 5 kHz / Vpk 55 / 4x | 0,00 % | 1,6e-6 | **1,8e-4** |
| `SINEFOLD`, 5 kHz / Vpk 55 / 4x | 0,00 % | 1,1e-6 | 4,1e-5 |
| `CUBIC`, 5 kHz / Vpk 55 / 4x | 0,00 % | 1,1e-5 | 1,1e-5 |
| `HARD`, 5 kHz / Vpk 55 / 4x | 0,00 % | 9,5e-6 | 9,6e-6 |
| `TANH`, 1 kHz / Vpk 30 / 1x | 0,00 % | 7,1e-8 | 7,1e-8 |
| `TANH`, 20 Hz / Vpk 55 / 1x | **0,50 %** | — | — |

1. **El fallback no toca los casos de §8.2:** a 5 kHz los seis `|du|` típicos son dos órdenes de magnitud mayores que
   `ε` y la fracción de muestras en fallback medida es **0,00 %** ⇒ los umbrales de alias de §7 se miden con ADAA
   efectivo, no con la ruta directa.
2. **Modelo analítico de la cota 2 confirmado.** La fracción de muestras en fallback de un seno es
   `(2/π)·ε/(A·Δθ)`. Para 20 Hz / 55 V / 48 kHz predice `0,44 %` y se miden `0,50 %`; la misma fórmula a 5 V da
   `4,9 %`, que es el `≈ 5 %` del punto 2. La dependencia `∝ 1/A` y `∝ ε` queda validada, no estimada a ojo.
3. **Error `float` vs `double`:** `≤ 1,8e-4` relativo (peor caso `FOLDBACK`) en barridos de 55 V de pico. Es el
   condicionamiento esperado de `ΔF` en simple precisión y queda ~40× por debajo del `0,7 %` del borde (`ε`).
4. **Prueba del límite inferior de `ε` (punto 3).** Peor caso de las seis: la cola lineal de `CUBIC` (`|u| > 2`,
   `F̃ = 3 − |u|`), donde `F` llega a `|F| ≈ 52` en `u = 55` y su `ulp` es `3,8e-6` (la única `F` no acotada cuyo
   cociente además vale exactamente `−1`). Con `|du| = 1,2e-3` (justo por encima de `ε`) el cociente en `float` se
   desvía hasta `ulp/|du| ≈ 3,2e-3` del valor exacto `TRIM[CUBIC]·(−1) = −0,9996`; medido `4,0e-4` (`y = −1,0000`).
   Es cuantización de `F`, no discontinuidad del algoritmo: la cota del teorema del valor medio sigue vigente. A
   `ε = 1e-4` el mismo `ulp` daría `3,8e-2` (**3,8 %**), que es exactamente el riesgo del punto 3.
5. **Riesgo de warning descartado.** `static const float ADAA_EPS` en cabecera tiene enlace interno, pero GCC solo
   activa `-Wunused-const-variable` en C++ con un flag explícito (no lo incluye `-Wall`): una unidad de traducción
   que incluya `Curves.hpp` sin llamar a `applyCurveAdaa` **no** rompe el criterio de 0 warnings.

```cpp
    adaaCurveApplied[0] = p.curveLow;
    adaaResync[0] = true;
  }
  if (p.curveMid != adaaCurveApplied[1]) {
    adaaCurveApplied[1] = p.curveMid;
    adaaResync[1] = true;
  }
  if (p.curveHigh != adaaCurveApplied[2]) {
    adaaCurveApplied[2] = p.curveHigh;
    adaaResync[2] = true;
  }
```

Orden de consumo en `process()`: `pendingOversampling` → `pendingCrossover` → `pendingAdaa` → `OSParams` →
detección de curva. `onSampleRateChange()` **no cambia** (§2: ε no depende de `fs`; el historial está en voltios).

## 5. Ruta por muestra (pseudo-código exacto)

```
IN ─► up ×N ─► LP/HP/(Mid = x-low-high)
                     │
                     ├─ u = curveDrive(banda, drive, curve)      (6: L/R × 3 bandas)
                     ├─ ADAA off ─► y = applyCurve(u, curve)      (ruta v2.5.0, bit-idéntica)
                     └─ ADAA on  ─► y = applyCurveAdaa(u, uPrev, curve)
                                      ├─ CLEAN/TUBE/DIODE ─► applyCurve(u), uPrev intacto
                                      ├─ |u-uPrev| < ε     ─► applyCurve(u)      (fallback)
                                      ├─ si no             ─► (F(u)-F(uPrev))/(u-uPrev)
                                      └─ uPrev = u
                     │
                     └─ pan/vol/solo ─► suma ─► down ×N ─► DC ─► MIX ─► OUT
```

Bloque literal que sustituye las 6 llamadas a `applyCurve` de `processBands` (líneas 363-376). `adaaOn` se lee
**una vez por bloque**; las 6 `u` se calculan antes del resync:

```cpp
  const int adaaOn = adaa;   // lectura unica por bloque (hoisted fuera del bucle)

  for (int i = 0; i < N; i++) {
    /* ... filtros: lowL/R, midL/R, upperL/R sin cambios ... */

    const float uLowL = coaldynamics::curveDrive(lowL, p.driveLow, p.curveLow);
    const float uLowR = coaldynamics::curveDrive(lowR, p.driveLow, p.curveLow);
    const float uMidL = coaldynamics::curveDrive(midL, p.driveMid, p.curveMid);
    const float uMidR = coaldynamics::curveDrive(midR, p.driveMid, p.curveMid);
    const float uHighL =
        coaldynamics::curveDrive(upperL, p.driveHigh, p.curveHigh);
    const float uHighR =
        coaldynamics::curveDrive(upperR, p.driveHigh, p.curveHigh);

    // Resync: uPrev = u en la PRIMERA submuestra del bloque, por banda y canal.
    // Tras el resync, applyCurveAdaa ve du = 0 -> fallback -> f(u), sin transitorio.
    if (adaaOn && i == 0) {
      if (adaaResync[0]) {
        uPrevLowL = uLowL;
        uPrevLowR = uLowR;
        adaaResync[0] = false;
      }
      if (adaaResync[1]) {
        uPrevMidL = uMidL;
        uPrevMidR = uMidR;
        adaaResync[1] = false;
      }
      if (adaaResync[2]) {
        uPrevHighL = uHighL;
        uPrevHighR = uHighR;
        adaaResync[2] = false;
      }
    }

    float wetLowL, wetLowR, wetMidL, wetMidR, wetUpperL, wetUpperR;
    if (adaaOn) {
      wetLowL = coaldynamics::applyCurveAdaa(uLowL, uPrevLowL, p.curveLow);
      wetLowR = coaldynamics::applyCurveAdaa(uLowR, uPrevLowR, p.curveLow);
      wetMidL = coaldynamics::applyCurveAdaa(uMidL, uPrevMidL, p.curveMid);
      wetMidR = coaldynamics::applyCurveAdaa(uMidR, uPrevMidR, p.curveMid);
      wetUpperL =
          coaldynamics::applyCurveAdaa(uHighL, uPrevHighL, p.curveHigh);
      wetUpperR =
          coaldynamics::applyCurveAdaa(uHighR, uPrevHighR, p.curveHigh);
    } else {
      // Ruta v2.5.0 exacta: mismas instrucciones que antes de v2.6.0.
      wetLowL = coaldynamics::applyCurve(uLowL, p.curveLow);
      wetLowR = coaldynamics::applyCurve(uLowR, p.curveLow);
      wetMidL = coaldynamics::applyCurve(uMidL, p.curveMid);
      wetMidR = coaldynamics::applyCurve(uMidR, p.curveMid);
      wetUpperL = coaldynamics::applyCurve(uHighL, p.curveHigh);
      wetUpperR = coaldynamics::applyCurve(uHighR, p.curveHigh);
    }

    /* ... pan/vol/solo, suma y medidor: SIN CAMBIOS ... */
  }
```

**Propiedades exigidas a este bloque**

- **Cero allocación / cero I/O / cero `std::function`.** Solo 6 `float` nuevos (2 por banda) + 3 `bool` + 3 `int`;
  ninguna indirección virtual; `applyCurveAdaa` y `curveAntiderivative` son `inline` de header → sin llamadas.
- **Ramas uniformes por bloque:** `adaaOn` es invariante dentro del bucle y `i == 0` es predecible; no hay rama por
  curva en `Saturator.cpp`: todo el `switch` vive en `Curves.hpp` como funciones `inline` de header.
- **`adaa = 0` ⇒ bit-idéntico a v2.5.0:** la rama `else` es literalmente la secuencia de instrucciones actual y el
  historial no se lee ni se escribe.
- **`CLEAN` ⇒ bit-idéntico a `adaa = 0`:** `applyCurveAdaa` corta en `curveSupportsAdaa()` y devuelve
  `applyCurve(u, curve)`; no hay media `(u+uPrev)/2`, no hay filtro de agudos oculto (T-ADAA-CLEAN).
- **`TUBE`/`DIODE`** caen por la misma puerta: ADAA no se aplica (fuera de alcance, criterio 9).
- **Latencia:** ADAA1 desplaza el instante efectivo de evaluación ~0,5 submuestras (0,125 muestras base a 4x). No
  toca `OS_LATENCY = 15` ni `dryDelay`; `T-LAT` y `T-MIX` no cambian.
- **CPU declarado:** `TANH` con ADAA = 2 `logCosh` por curva → 2 libm/call (`sinh`+`log1p` o `exp`+`log1p`),
  12 llamadas por submuestra (6 curvas × 2) ≈ 9 % de un core a 4x/48 kHz. Presupuesto a **verificar** con `make test`
  + CPU meter; si se excede, la optimización futura es cachear `F(uPrev)` (cambiaría el estado a 12 floats: **fuera
  de este contrato**).

### 8.3 Metodología de T-ADAA-THD (enmienda 2026-11-02)

Punto de operación del caso (fila `T-ADAA-THD` de §8.2 y criterio 5 de `specs/v2.6_quality_spec.md` §7): curva
`TANH`, 1 kHz, Vpk 5, drive 6 (knob 0,5), `n = 1`, `mix = 1`, `outVol = 1`, `vol = 1`, `lr4 = 0`; umbral
**ΔTHD+N ≤ +0,5 dB**. La enmienda no toca el umbral ni el setup: fija **sobre qué señal se mide**. La medida se toma
de la **banda Mid aislada** (`soloBand = 1`) y no de la suma de las tres bandas.

Medido el 2026-11-02 en el mismo punto de operación, con `n = 1`:

| Configuración | THD+N `adaa=0` (dB) | THD+N `adaa=1` (dB) | Δ (dB) | ¿Cumple +0,5? |
|---|---:|---:|---:|---|
| 3 bandas (suma) | −1,25 | −0,66 | **+0,589** | no |
| solo Low | −12,50 | −12,57 | −0,069 | sí |
| solo Mid | −3,93 | −3,55 | **+0,379** | sí |
| solo High | −12,91 | −12,98 | −0,069 | sí |

**`soloMid` reproduce el operador aislado.** El Δ de la banda Mid coincide al dígito con el del operador medido sin
cadena (`applyCurve` vs `applyCurveAdaa`, 1 kHz, Vpk 5, g = 6: −3,93 → −3,55 dB, Δ = +0,379 dB) ⇒ la banda Mid
reproduce exactamente **una instancia** de ADAA1, sin ganancia, filtro ni normalización añadidos por la cadena. El
exceso de +0,21 dB de la suma es **reconstrucción**, no algoritmo: al comprimirse el pico de la banda Mid, el
fundamental de la suma baja mientras la distorsión de Low y High —que apenas cambia, −0,069 dB— se mantiene, y el
cociente THD+N sube. La separación es exacta: `+0,589 − (+0,379) = +0,210 dB`.

Dependencia con el factor de sobremuestreo (3 bandas, `TANH`, 1 kHz):

| `n` | Δ (dB) |
|---:|---:|
| 1 | +0,589 |
| 2 | −0,115 |
| 4 | −0,016 |
| 8 | −0,004 |

A 5 kHz / `n = 1` el Δ es **−3,340 dB** (mejora): allí domina la reducción de alias y el efecto descrito queda
sumergido.

**Mecanismo.** ADAA1 devuelve la media de `f` sobre el intervalo `[uPrev, u]`, no `f(u)`; el error de esa media
frente a la evaluación puntual crece con el salto por muestra `Δu ≈ 2π·f/fsN · Vpk·drive`. A 1 kHz, `n = 1`,
48 kHz y drive 6: `2π·1000/48000 · 30 ≈ 3,9`, un salto comparable a la escala de `tanh` (`|u| ~ 1`), así que la curva
efectiva resulta algo más compresiva en los picos → más armónicos in-band. A 100 Hz el mismo cálculo da
`Δu ≈ 0,39` y el efecto medido es 0,000 dB; a 5 kHz domina la reducción de alias. El factor `n` reduce `Δu` en
proporción directa (`fsN = fs·n`), que es exactamente la tabla de arriba.

**Consecuencia operativa.** `T-ADAA-THD` mide **una instancia** del operador ADAA1. No pretende validar la suma de
tres bandas saturadas: con `drive 6` y `TANH` esa suma queda en un régimen de distorsión ≈ 80 % (THD+N de la suma
≈ −1 dB), donde el criterio de ΔTHD+N no discrimina el operador porque mezcla su efecto con el reparto espectral de
la reconstrucción. La cobertura de la cadena completa la dan los casos de alias (`T-ADAA-FOLD/SINE/TANH`, §8.2) y
`T-ADAA-CLEAN`.

**Trazabilidad.** Lo implementa `thdNAdaa(int curve, float drive, int adaaOn)` en `test/harness.cpp`, que fija
`ch.p.soloBand = 1` y `ch.p.adaa = adaaOn` sobre `ch.configure(FS, 1)`; `caseAdaaThd()` compara on/off y aplica el
umbral. Resultado del gate: **+0,3786 dB**, margen **0,12 dB** sobre el límite de +0,5 dB. `make test` y
`make test-strict`: `RESUMEN casos=12 PASS=12 XFAIL=0 FAIL=0`; build con 0 warnings.
