### 2.1 Snippet del struct (insertar antes de `struct Saturator;`)

```cpp
struct MakeupParamQuantity : ParamQuantity {
  std::string getDisplayValueString() override {
    float v = getValue();
    if (v <= 1e-6f)
      return "-inf";
    float db = 20.f * std::log10(v);
    if (db > -0.005f && db < 0.005f)
      return "0.00";
    return string::f("%+.2f", db);
  }
};
```

Formato fijado: `%+.2f` (2 decimales, signo `+` en positivos), guardia de coma flotante
(`db > -0.005f && db < 0.005f`) -> `0.00`; `0` o `<=1e-6` -> `-inf`. Tooltip: Rack concatena
`getDisplayValueString() + " " + unit`; con unit `" dB"` (espacio inicial) y string numerico
el resultado final es `0.00 dB` / `+12.04 dB` (evitar `dB dB`).
